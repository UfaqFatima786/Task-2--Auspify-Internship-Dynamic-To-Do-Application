## 📌 About The Project

**TaskFlow** is a modern and interactive To-Do Application developed as **Task 2 of my Auspify Internship**. It is designed to help users organize daily activities, manage pending tasks, track completed work, and monitor their productivity through a clean and user-friendly dashboard.

Built with HTML5, CSS3, and JavaScript (ES6 ), this project focuses on dynamic user interactions, responsive web design, and local data persistence using the browser's LocalStorage.

The application combines practical task management functionality with a polished interface to make everyday planning simple and efficient.

## ✨ Features

- ➕ **Add Tasks:** Quickly add new tasks to your personal task list.
- ✅ **Task Completion:** Mark tasks as completed and track your progress.
- 🗑️ **Delete Tasks:** Remove individual tasks when they are no longer needed.
- 📈 **Daily Progress Tracker:** Monitor your task completion percentage with a dynamic progress bar.
- 🧹 **Clear Completed Tasks:** Remove completed tasks from the list.
- 💾 **LocalStorage Support:** Keep your tasks saved in your browser across page refreshes.
- 🎨 **Modern Dashboard UI:** Enjoy a clean layout with organized sections, visual statistics, and an intuitive interface.
- ⚡ **Dynamic Interactions:** Update task lists and productivity statistics without manually refreshing the page.
- ♿ **Usability-Focused Design:** Includes clear labels, helpful empty states, and accessible task status feedback.

## 🖥️ Application Overview

TaskFlow provides a centralized workspace for managing everyday tasks.

- **My Tasks:** Access your task management dashboard.
- **Task Overview:** Navigate to the task list section.
- **Statistics Dashboard:** Review task counts and completion progress.
- **Task List:** Add, complete, filter, and clear tasks.
- **Local Data Storage:** Retain saved tasks between browser sessions.
